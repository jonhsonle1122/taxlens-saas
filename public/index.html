Thuật Toán Kiểm Định Checksum Mã Số Thuế 63 Tỉnh Thành

📐 Cơ Chế Tính Checksum Modulo 11:

S = (d₁×31 + d₂×29 + d₃×23 + d₄×19 + d₅×17 + d₆×13 + d₇×7 + d₈×5 + d₉×3) mod 11
d₁₀ (Số kiểm tra) = 10 - S

Chữ số kiểm tra tính toán hoàn toàn trùng khớp với chữ số cuối cùng của MST.

Tài Liệu Tích Hợp API (RESTful)

Tích hợp tính năng bóc tách hóa đơn điện tử TT78 và kiểm tra mã số thuế vào phần mềm quản lý, ERP hoặc app nội bộ của bạn chỉ với vài dòng code.

1. Bóc Tách Hóa Đơn Điện Tử (POST /api/v1/extract-invoice)

curl -X POST http://localhost:3001/api/v1/extract-invoice \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "rawText": "Nội dung hóa đơn điện tử hoặc chuỗi XML...",
    "sampleId": "fpt_retail"
  }'

2. Tra Cứu & Xác Thực Mã Số Thuế (POST /api/v1/verify-taxcode)

curl -X POST http://localhost:3001/api/v1/verify-taxcode \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "taxCode": "0303490096"
  }'

3. Dành Cho Autonomous AI Agents (Giao Thức x402 & ERC-8004)

Các bot tự hành có thể gọi API và thanh toán vi mô 0.005 USDC/request trực tiếp trên mạng Base L2 mà không cần thẻ tín dụng:

# Lấy Discovery Manifest theo chuẩn ERC-8004
curl http://localhost:3001/.well-known/erc-8004.json

# Gọi kèm chứng từ thanh toán on-chain (Base L2)
curl -X POST http://localhost:3001/api/v1/extract-invoice \
  -H "Content-Type: application/json" \
  -H "X-Payment-Proof: 0x8f23...a7b4" \
  -d '{"sampleId": "fpt_retail"}'

🛡️ Cam kết bảo mật (Nghị định 13/2023/NĐ-CP): Hệ thống xử lý dữ liệu in-memory, tuyệt đối không lưu trữ nội dung hóa đơn của khách hàng trên cơ sở dữ liệu.
